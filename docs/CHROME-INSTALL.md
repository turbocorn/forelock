# Forelock Music Bridge — локальная установка

Нужен обычный Google Chrome 120+ и собранный `Forelock.app`. Расширение не работает в Яндекс Браузере или in-app browser Codex. Native host — отдельный Swift executable внутри приложения, без Python/Node во время работы.

1. Соберите и установите Forelock:

   ```sh
   ./chelka-lab/native/scripts/build.sh
   ditto chelka-lab/native/build/Forelock.app "$HOME/Applications/Forelock.app"
   ./chelka-lab/native/scripts/install-chrome-bridge.sh
   ```

2. В Chrome откройте `chrome://extensions`, включите режим разработчика, нажмите **«Загрузить распакованное расширение»**, выберите папку `chrome-extension` из этого репозитория.
3. Проверьте ID: **`ngdjfmcmoedjlgpahbolpfkhbbfmpeml`**. Он закреплён публичным ключом manifest; приватного ключа в репозитории нет.
4. Откройте Forelock. Перезагрузите только нужную музыкальную вкладку: `https://music.yandex.ru/`, `https://music.yandex.com/` или `https://zvuk.com/`. Включите настоящий трек. В раскрытом Forelock должны появиться метаданные.
5. При нескольких источниках используйте меню источника в музыкальном блоке. Автоматический режим отдаёт приоритет реально играющему источнику; явный выбор фиксирует выбранный плеер до его исчезновения.

Расширение получает `nativeMessaging` и доступ **только** к трём перечисленным HTTPS-доменам. Нет разрешений `tabs`, `history`, `cookies`, `debugger`, `webRequest`, микрофона, записи экрана или системного звука. Оно не запрашивает список вкладок: получает только подключения собственных content scripts на разрешённых страницах.

На стороне страницы используются публичные `navigator.mediaSession.metadata/playbackState`, свойства HTMLMediaElement и доступные кнопки плеера. Приватные JS-объекты сайта, перехват сетевых запросов, cookies и токены не используются. Media Session не предоставляет getter зарегистрированных action handlers или текущей позиции; команды включаются по доступным HTMLMediaElement/DOM-кнопкам, позиция — по media element или числовым атрибутам ползунка Яндекса. Неизвестная команда остаётся отключённой. Звук проверен только на настоящих гостевых фрагментах; полное прослушивание требует входа и отдельно не проверено. Приложение Яндекс Музыки этим расширением не подключается. Подробности — в [матрице проверки](../chelka-lab/native/ACCEPTANCE.md).

Chrome запускает host через `allowed_origins`; host независимо проверяет origin аргумента запуска. Сообщения ограничены 64 KiB, проходят проверку версии, типа, домена, полей и команд. Связь с Forelock — Unix socket с правами 0600 в каталоге 0700 текущего пользователя; TCP-сервера нет. Как и другие native messaging hosts, эта граница не защищает от произвольной программы, уже выполняющейся под тем же пользователем macOS.

Если соединения нет, проверьте путь в `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.turbocorn.forelock.music.json`, наличие executable внутри Forelock.app и ID расширения. После переноса .app повторите install-скрипт. При смене ID host отклонит подключение. Host не запускает Forelock или Music.app автоматически.

Чтобы отключить мост, удалите расширение обычной кнопкой Chrome. Локальный manifest host можно убрать из указанного каталога. Музыкальные данные не сохраняются на диск. При закрытии вкладки источник удаляется; при потере сообщений он истекает через 7 секунд.
