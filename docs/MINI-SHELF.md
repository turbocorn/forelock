# Forelock 0.5.2 — результат File Drop

Мини-полка заменяет прежнее подтверждение на 1,25 с. Это временное представление существующего ShelfModel в том же NSPanel; новое хранилище или отдельное файловое окно не создаётся. File Drop 2.0, верхняя геометрия, музыка и обычный hover policy сохранены.

После импорта сохраняются только ID реально добавленных ShelfItem, число попыток и текст ошибок. Миниатюры, имена и URL копий берутся из существующей полки. До четырёх файлов видны сразу; если их больше четырёх, показаны три карточки и +N. Старые файлы полки не подмешиваются в последний импорт.

- Нажатие карточки открывает существующий EmbeddedQuickLook в той же поверхности. «К добавленным», нижнее «Назад» и Escape из этого просмотра возвращают в тот же результат импорта. Обычный просмотр из полной Shelf сохраняет прежний возврат.
- Карточка — тот же NativeFileTile/DraggableFileView, что в основной полке. Можно сразу потянуть в Finder/другое приложение; операция по-прежнему copy. Из Quick Look сначала вернитесь к добавленным файлам.
- «Все файлы» и +N открывают существующую полноценную Shelf, закреплённую до явного закрытия. Содержимое хранится независимо от того, видна ли мини-полка.
- У мини-полки нет таймера общего времени жизни. Пока курсор внутри контура/камеры, нажата кнопка, идёт drag-out либо модальное взаимодействие, дедлайн закрытия сбрасывается. После непрерывного выхода на 0,8 с она сворачивается. Повторный вход отменяет закрытие.
- Если drop начался из закреплённого Обзора, Shelf, просмотра или настроек, автоматический выход возвращает этот экран. Слева есть стрелка с названием прежнего контекста. Из Idle/Hover возврат ведёт в Idle. Крестик — явное закрытие Forelock. Собственный исходящий drag не превращается во входящий импорт.
- При частичном успехе видны только успешные копии, фактическое «Добавлено N из M» и ошибка с именем файла/причиной. До двух строк ошибки видны в блоке; полный текст доступен при наведении и через accessibility. При полном отказе нет фиктивных карточек, показана ошибка. ShelfModel.error также сохраняется для полного экрана.

Состояния готовности и копирования сохраняют 520 × 208 pt на текущем экране; мини-полка использует тот же размер. Для Quick Look и полной Shelf действуют существующие размеры, верхний якорь и SurfaceSpring. Reduced motion работает через прежний контроллер.

Мини-полка 0.5.1 принята на `feature/drop-mini-shelf` (`cb679b8`); текущее групповое выделение находится в `feature/shelf-multi-selection`. Полная фактическая проверка, включая ответ пользователя о настоящем жесте, — [ACCEPTANCE.md](../chelka-lab/native/ACCEPTANCE.md).

Принятый установленный bundle 0.5.1 сохранён локально в `chelka-lab/native/artifacts/rollback-0.5.1/Forelock.app`. Для отката завершите Forelock и из корня репозитория выполните `./chelka-lab/native/scripts/rollback-0.5.1.sh`, затем откройте приложение. Полка не очищается. Сохранённые ранее 0.4.1 и 0.4.0 также остаются на месте.

В 0.5.2 добавлено [выделение группы](SHELF-SELECTION.md): Cmd+клик и Cmd+A при фокусе полки. Cmd+A включает файлы за +N. Выбранная карточка выносит всю группу, невыбранная — только себя. Пока нажата кнопка, идёт drag-out или пользователь удерживает модификатор выделения при фокусе полки, автосворачивание приостановлено. После взаимодействия действует прежняя задержка выхода. Выделение само по себе не отменяет автосворачивание навсегда.
