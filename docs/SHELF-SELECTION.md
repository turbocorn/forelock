# Forelock 0.5.2 — Shelf Multi-Selection

База: принятая 0.5.1, `feature/drop-mini-shelf`, `cb679b8`. Реализация в отдельной ветке `feature/shelf-multi-selection`; main не изменяется. Версия .app — 0.5.2 / 52.

## Жесты и клавиатура

| Действие | Результат |
| --- | --- |
| Обычный клик карточки | Прежний Quick Look; выделение очищается, карточка становится якорем диапазона |
| Cmd+клик | Добавить или убрать ID из выделения |
| Shift+клик в полной Shelf | Диапазон от последнего якоря в порядке сетки; Cmd+Shift добавляет диапазон к группе |
| Cmd+A | Все файлы активной полки, только при её клавиатурном фокусе |
| Escape | Сначала снять выделение; следующее нажатие — прежнее закрытие/возврат |
| Потянуть выделенную карточку | Копировать всю выбранную группу |
| Потянуть невыделенную карточку | Копировать только её, сохранив остальное выделение |

Mini Shelf поддерживает Cmd+клик и Cmd+A; диапазон нужен только полной Shelf. Cmd+A в Mini выбирает весь последний импорт, включая скрытые за +N элементы. «Все файлы» переносит выбор в полную полку. Плеер, настройки, Quick Look, текстовые поля и посторонние окна не перехватывают этот Cmd+A.

Выделенные карточки имеют светлую рамку, спокойный фон и отметку. В прежней боковой секции полной Shelf или верхней строке Mini видны количество, «Удалить копии» и «Снять выделение». Поверхность не расширяется ради этих действий. Обычный клик и прежний возврат из Quick Look сохранены.

## Нативный перенос

Прежний DraggableFileView формирует несколько NSDraggingItem и передаёт их одним beginDraggingSession. Каждый writer — настоящий URL сохранённой копии; изображения получаются из тех же миниатюр ShelfModel. Порядок группы совпадает с активной полкой, операция — только copy для обоих NSDraggingContext. Модификаторы не превращают её в move. Перенос предназначен для Finder и приложений, принимающих файловый drop; конкретное стороннее приложение всё равно определяет поддерживаемые типы.

Состав группы фиксируется при начале drag. Успешный перенос и отмена не удаляют копии и не меняют выбор. Поздний mouseUp после окончания/отмены не открывает Quick Look и не переключает выделение. Пока идёт выделение мышью или перенос, Mini не закрывается; после выхода остаётся её прежняя задержка 0,8 с. Выделение без взаимодействия не закрепляет Mini навсегда.

## Удаление и хранение

Удаление запускается явной кнопкой с видимым количеством выбранных элементов, без новой клавиши Delete и без рутинного подтверждения. Это прежняя семантика удаления **копий Forelock**: исходные URL Finder не передаются операции удаления. ShelfRepository и формат shelf.json не изменены.

ShelfModel последовательно вызывает существующий repository.remove только для захваченных выбранных ID. Во время операции повторные действия блокируются. Успешные ID удаляются из выделения и миниатюр, ошибки сохраняются; неудачные копии остаются для повторной попытки. Выделение — только временный набор ID/якорь, в manifest не записывается. Перезапуск не восстанавливает его.

Сквозной перенос группы из полной и мини-полки пользователь подтвердил настоящей мышью. Другая проверка — [ACCEPTANCE.md](../chelka-lab/native/ACCEPTANCE.md). Веб- и мобильных тестов нет; музыкальные провайдеры и MediaRemote не изменены.

Завершите Forelock, выполните из корня `./chelka-lab/native/scripts/rollback-0.5.1.sh` и снова откройте приложение. Хранилище не очищается, копии, добавленные в 0.5.2, остаются совместимыми с 0.5.1.
