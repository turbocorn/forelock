# Forelock — продуктовая основа

8 ноября 2026. Текущая реализация 0.5.2 включает File Drop 2.0, мини-полку и выделение/group drag-out. Направления ниже — план, а не обещание уже работающих функций. Один интерфейс у чёлки; существующие геометрия и музыкальные провайдеры сохраняются.

## Clipboard / Shelf

**Clipboard — автоматическая ограниченная история копирования.** Найти ранее скопированный текст или ссылку, вернуть изображение/скриншот, повторно скопировать файл. Скриншот входит в историю, только если пользователь отправил его в clipboard; это не глобальная история всех снимков экрана.

macOS: [NSPasteboard](https://developer.apple.com/documentation/appkit/nspasteboard) предоставляет элементы/типы, чтение и запись; `changeCount` позволяет замечать смену содержимого. Для файлов история может хранить ссылку, которая станет недействительной после перемещения/удаления оригинала. Автоматическое копирование больших файлов требует отдельного решения о лимитах и стоимости хранения. Требования доступа надо проверить на целевых версиях macOS перед реализацией.

Приватность до поиска: явное включение, пауза, список исключённых приложений, исключение чувствительных/одноразовых записей, лимиты по сроку, количеству и объёму, полная очистка. Активное приложение — лишь приблизительный признак автора копирования: универсальная достоверная атрибуция и обнаружение всех секретов не обещаются. При неопределённости источник/элемент безопаснее пропустить; нужны проверки на настоящих password managers и Universal Clipboard.

**Shelf — намеренно сохранённые копии.** Перенести из Finder либо выбрать «На полку» в Clipboard; закрепить важное, выбрать несколько элементов, вынести группу в другое приложение, удалить выбранное или очистить незакреплённое. Попадание в Clipboard само по себе ничего не добавляет в Shelf навсегда. Удаление копии не удаляет оригинал. Формат нынешнего хранилища в 0.5 не меняется.

Приоритет: **P0** удобный drop и отмена (сейчас); **P1** мультивыбор/group drag-out реализованы локально в 0.5.2; далее закрепление и явная очистка; **P2** Clipboard с privacy/retention до сохранения истории, затем поиск и перенос на Shelf. Границу данных сохранить даже при будущем общем интерфейсе.

## Media

Сценарии: продолжить музыку, выбрать реально играющий источник; увидеть доступный аудиовыход, переключить его; заметить подключение/отключение устройства и доступный заряд.

Основа — существующий MusicProvider. [Core Audio](https://developer.apple.com/documentation/coreaudio) позволяет перечислять аудиоустройства, следить за изменениями и работать с default output; перед переключением проверять, что устройство живо и свойство доступно для записи. Это системный выход, не обещание отдельной маршрутизации каждой сторонней программы.

Заряд MacBook — публичный IOKit Power Sources (`IOPSCopyPowerSourcesInfo`, уведомления). Проценты аксессуаров показывать только при реально доступном подтверждённом источнике: наличие Bluetooth-соединения не гарантирует доступ к батарее, универсальная поддержка AirPods/всех аксессуаров не заявляется. CoreBluetooth и device-specific возможности исследовать только под конкретные устройства; не использовать частные поля как продуктовую гарантию.

Приоритет: **P1** сохранить рабочую музыку и сделать отдельную проверку Core Audio output + батареи MacBook; **P2** подключение/отключение и список подтверждённых аксессуаров с пометкой недоступных данных. В 0.5 ничего из Devices не реализуется; экспериментальный MediaRemote сохраняет свои прежние ограничения.

## Live Activities

Сценарии: увидеть копирование/ошибку Forelock, оставшееся время собственного таймера, завершение или запрос действия от явно подключённой задачи Codex/Claude Code.

Собственные операции имеют достоверный lifecycle/progress и ID. Таймер хранит deadline и пересчитывается после сна. Публичные [уведомления NSWorkspace](https://developer.apple.com/documentation/appkit/nsworkspace) дают конкретные события запуска/завершения приложений, сна/пробуждения и монтирования томов. Наличие приложения не означает наличие информации о выполняемой им задаче.

Codex/Claude Code потребуют отдельного адаптера к подтверждённому интерфейсу или явно настроенным hooks. Контракт: task ID, источник, running/completed/needs-action, время события, отмена/истечение, переподключение и согласованные действия. Без чтения чужих терминалов/логов по умолчанию. **Глобальное отслеживание всех загрузок браузеров, копирований Finder и операций сторонних приложений не обещается**: для каждого источника сначала подтверждается поддерживаемый механизм.

Приоритет: **P1** статусы собственных операций; **P2** собственные таймеры и один проверенный внешний адаптер; **P3** отдельные системные события с дедупликацией и ограничением шума. В 0.5 реализовано лишь краткое состояние текущего файлового drop, не общий движок Activities.
