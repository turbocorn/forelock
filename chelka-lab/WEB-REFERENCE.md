# Чёлка — macOS Notch Motion Lab

Самостоятельный локальный прототип на React + TypeScript + Vite. Три разные модели взаимодействия с чёлкой MacBook: непрерывная поверхность, орбиты событий и магнитная полка.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Открыть **http://127.0.0.1:5187/**. Порт фиксирован, чтобы адрес прототипа оставался предсказуемым. Для другого порта: `npm run dev -- --port 5190`.

```sh
npm run build     # TypeScript и production-сборка
npm run preview   # локальный просмотр production-сборки
```

Шрифт, иллюстрации, иконки и обои локальные. Прототип не требует API, аккаунтов или внешних медиа. Музыка и события симулируются; аудио не воспроизводится.

## Что попробовать

**01 / Liquid**

- Начальный раскрытый плеер: пауза, следующий/предыдущий трек, перемотка, громкость и mute.
- В пульте выбрать «Компактно», навести курсор на чёлку: появляется мини-плеер. Нажать на обложку или значок раскрытия.
- Увести курсор: временный мини-плеер вернётся в компактное состояние. Явно выбранный «Мини» остаётся открытым.
- Быстро переключать размеры: пружина продолжит движение с текущего положения. Внутреннее содержимое сохраняет свою геометрию и раскрывается через маску поверхности.

**02 / Orbit**

- Добавлять события Codex, AirPods Pro и скриншота из пульта.
- Нажимать заголовки капсул: одновременно раскрыта только одна, остальные остаются компактными.
- Стрелка вверх возвращает событие в чёлку; крестик закрывает окончательно. Нажатие на чёлку возвращает сохранённые события.
- «Принять» в Codex сохраняет просмотренный результат внутри чёлки.
- Очередь содержит последние шесть событий. При заполнении она прокручивается; новое раскрытое событие появляется в видимой области.
- Escape сначала закрывает подробности, повторное нажатие собирает события в чёлку.

**03 / Shelf**

- Перейти в Shelf и перетащить один или несколько файлов из Finder в область чёлки. Можно начать со свёрнутой полки — она раскроется при появлении файлов.
- При приближении файла поверхность расширяется и слегка тянется навстречу. Верхний край остаётся закреплённым, содержимое смещается мягко.
- «Поднести файл» демонстрирует магнитное поле без Finder. «Демо-файлы» добавляет настоящие локальные File/Blob объекты, которые можно просмотреть и скачать.
- Нажать на файл для просмотра изображения или текста. Другие форматы показывают метаданные и кнопку сохранения.
- Крестик убирает файл. Стрелка под файлом сохраняет оригинал на Mac. Карточка поддерживает drag-out (`DownloadURL` и `text/uri-list`); передача файла напрямую в Finder зависит от браузера, надёжный запасной путь — кнопка сохранения. Рекомендуется Chrome.
- Файлы остаются в памяти вкладки при переключении концепций и повторе сцены. Закрытие/перезагрузка вкладки очищает полку. Файлы никуда не отправляются. Максимальный размер одного файла — 100 МБ; папки не поддерживаются.

## Управление

| Действие | Управление |
| --- | --- |
| Переключить концепцию | Вкладки или `1`, `2`, `3` |
| Перейти между вкладками с клавиатуры | `←`, `→`, `Home`, `End` |
| Повторить сцену | Круговая стрелка или `R` |
| Свернуть / закрыть просмотр | `Escape` |
| Увеличить рабочую сцену | Значок фокус-режима справа |
| Замедлить пружины | Переключатель «Замедлить» |
| Уменьшить движение | «Меньше движения» или системная настройка macOS |

Системный `prefers-reduced-motion` имеет приоритет. В этом режиме отключены пространственные переходы и декоративные циклы, все функции остаются доступны. Окна просмотра удерживают клавиатурный фокус и возвращают его после закрытия. Сочетания концепций не перехватываются при вводе в поля и открытом диалоге.

## Проверка

Тесты используют Playwright и установленный Google Chrome:

```sh
npm run test:e2e
```

Если локальный сервер ещё не запущен, Playwright запустит его автоматически. Скриншоты раскрытых концепций:

- `artifacts/liquid-expanded.png`
- `artifacts/orbit-expanded.png`
- `artifacts/shelf-expanded.png`

Также сохраняются изображения шириной 390 и 768 px. HTML-отчёт — `artifacts/report/index.html`.

Проверяются управление плеером, непрерывность spring-интерполяции по кадрам, прерывание переходов, положение верхнего края, отсутствие наложения капсул и подсказки, очередь событий, native DataTransfer с реальными File, просмотр/скачивание/удаление, drag-out payload, сохранность файлов при переключении, Escape, клавиатура, reduced motion и адаптивная геометрия. Тест DataTransfer проверяет браузерную сторону drag-and-drop; взаимодействие с системным Finder вручную проверяется указанным выше сценарием.

## Motion для последующего переноса

Единая базовая пружина: `stiffness: 340`, `damping: 31`, `mass: 0.9`. Замедленная: `110 / 23 / 0.9`. Эти коэффициенты описывают web-поведение; при переносе в SwiftUI потребуется визуальная калибровка.

- **Liquid:** якорь в центре верхней грани; 206 × 39 → 330 × 87 → 420 × 260. Пружина меняет размеры оболочки, содержимое имеет постоянную ширину, выход за границы скрыт маской.
- **Orbit:** чёлка 184 × 40; независимые капсулы появляются с уменьшением и смещением, сворачиваются обратно к источнику. Список ограничен по высоте и не заходит на dock/подсказки.
- **Shelf:** 214 × 41 → 440 × 242 или 440 × 288. Притяжение начинается в зоне ±300 px от центра, добавляет до 18 px горизонтального намерения и до 16 px вертикального; внешняя форма растёт, внутреннее содержимое следует с меньшим коэффициентом. Верхний якорь неподвижен.

Настоящие AppKit drag sessions, системное размещение поверх меню, камера и музыкальные интеграции оставлены для нативного этапа.
