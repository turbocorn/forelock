# Forelock 0.5.2 — Shelf Multi-Selection

8 ноября 2026. **0.5.2 / 52** собрана, установлена в `~/Applications/Forelock.app` и запущена на реальном MacBook / macOS 15.7.3 / Apple Silicon. База — принятая 0.5.1, `feature/drop-mini-shelf`, `cb679b8`. Новая ветка — `feature/shelf-multi-selection`; merge в main не выполняется. Прежний отчёт сохранён в [ACCEPTANCE-0.5.1.md](ACCEPTANCE-0.5.1.md).

## Главный критерий — подтверждён пользователем

После установки пользователь получил два конкретных вопроса о настоящих действиях мышью/трекпадом:

1. Cmd+клик 2–5 файлов → потянуть выбранную карточку в Finder, затем повторить из Mini Shelf после нового File Drop. Ответ: **«Оба переноса работают»**.
2. Shift-диапазон в полной Shelf, Cmd+A, Escape сначала снимает выделение, отмена drag, удаление нескольких тестовых копий, обычный клик/Quick Look, Hover и музыка. Ответ: **«Всё работает»**.

Таким образом, групповой перенос из обеих полок и перечисленные регрессии подтверждены человеком на установленной 0.5.2. Эти ответы не подменяются unit-тестами. Реально проверенное внешнее назначение — Finder; произвольные сторонние приложения по отдельности не заявляются проверенными, хотя используется стандартный файловый NSDraggingSession.

## Что реализовано

- Временный набор выбранных ID и якорь; Shift использует полный порядок текущей сетки. Cmd переключает ID, обычный клик сохраняет Quick Look. В Mini Cmd+A охватывает весь последний импорт, включая +N.
- Cmd+A обрабатывается только в key NSPanel, когда first responder — файловая карточка с поддержкой выделения либо focus marker активной полки. Quick Look, текстовые поля, плеер/настройки и посторонние окна исключены. Focus marker не принимает mouse hit test и не перекрывает кнопки.
- Escape сначала снимает выделение; следующий — прежняя логика. Выделение визуально обозначено рамкой, фоном и отметкой. В полной Shelf действия находятся в прежней правой секции, в Mini — в компактной строке.
- DraggableFileView передаёт один массив настоящих NSDraggingItem, каждый с URL существующей сохранённой копии. Выбранная карточка выносит всю группу в порядке полки; невыбранная — только себя. Операция copy для обоих dragging context, без удаления из Forelock. Успех и отмена не меняют выбор; поздний mouseUp не открывает Quick Look и не переключает его.
- «Удалить копии» захватывает только выбранные ID. ShelfModel вызывает существующий repository.remove последовательно, убирает успешные ID и сохраняет ошибки/неудачные элементы для повторной попытки. Оригиналы не участвуют в удалении. Нет нового shortcut Delete и рутинного диалога подтверждения; действие явное и рядом показано количество.
- Mini удерживается во время нажатия/выделения и drag-out. Её прежнее автосворачивание после выхода сохраняется, полная Shelf закреплена. После удаления счётчик/карточки актуализируются, Cmd+A не захватывает старые файлы вне последнего импорта.

Подробная инструкция: [SHELF-SELECTION.md](../../docs/SHELF-SELECTION.md).

## Наблюдалось инструментально в установленном .app

Открыта настоящая полная Shelf. Cmd+A выделил все три находившиеся в ней реальные копии: AX показал Value «Выбрано» у трёх карточек, счётчик «Выбрано: 3» и обе кнопки действий. Реальный снимок осмотрен: рамки, отметки, миниатюры, названия и правые действия помещаются в прежний контур без обрезания. Пользовательские копии инструментом не удалялись.

Инструментальный Cmd+клик и последующий Escape не записаны как успешная физическая проверка: собственные события Forelock показали обычный outside-click при указателе вне поверхности, который сворачивал панель. Физические Cmd/Shift, Escape и drag затем отдельно проверены пользователем, ответы приведены выше. Обычный Hover и музыкальные данные наблюдались при раскрытии установленного приложения; отдельные providers не изменялись и музыкальные приложения для этой работы не запускались автоматически.

## Автоматические проверки — изменённая логика

Финальный целевой запуск `swift test --filter 'ShelfSelectionTests|MiniShelfTests'` в настоящей WindowServer-сессии: **14 тестов, 0 ошибок, 0 пропусков**. Это девять новых selection-тестов и пять существующих Mini-тестов, затронутых изменением карточки/взаимодействий.

Новые проверки:

- Cmd toggle, обратные/прямые/добавочные диапазоны, порядок группы, отсечение удалённых ID и одиночный drag невыбранной карточки.
- Обычный клик → Quick Look и якорь диапазона после возврата; уход в Обзор очищает выбор.
- Настоящие несколько NSDraggingItem и отдельный тестовый pasteboard: получены все URL реальных копий, существующие на диске и отличающиеся от оригиналов. Cmd+A формирует группу пяти.
- Отмена drag и поздний mouseUp не открывают файл/не переключают выбор; следующий обычный жест продолжает работать.
- Реальное key-window/first responder ограничение Cmd+A, исключение NSTextView/нефайлового экрана; Escape сначала снимает выбор.
- Удаление трёх тестовых копий сохраняет оригиналы и две невыбранные копии; перезагрузка прежнего repository даёт корректный список. Повреждённый тестовый manifest блокирует удаление, оставляя файлы, выбор и ошибки для повторной попытки.
- Mini Cmd+A включает +N, выбор/drag удерживают поверхность, переход в полную Shelf сохраняет группу и закреплённость.
- Удаление выбранных новых файлов в Mini не затрагивает прежние элементы; следующий Cmd+A охватывает только оставшийся последний импорт.
- Нативные виды выделения и существующий accessibility toggle отрисованы с настоящими изолированными копиями.

Локальные рендеры production views: `native/artifacts/0.5.2/full-selected.png`, `mini-selected.png`, `mini-selected-error.png`. Это тестовые состояния, не скриншоты настоящего Finder drag. Осмотрены полная группа пяти, Mini с тремя карточками/+2 и Mini с ошибкой — элементы не перекрываются, текст и действия помещаются. Веб-/мобильные тесты не запускались.

## Сохранённая основа

Без изменений относительно cb679b8: ForelockMusic, MusicCoordinator/MusicViews, MediaRemote host/vendor, ShelfRepository и manifest format, DropHostingView, FileDragProbe/FileDropLayout, NotchGeometry/SurfaceSpring и NotchPointerPolicy. Изменён только необходимый native drag source, временное выделение, действия ShelfModel и UI полки/клавиатурный routing. Выделение не записывается на диск. Clipboard, закрепление и очистка по сроку не добавлены.
