# Forelock 0.5.3 — Live Surface Core

8 ноября 2026. Установлена **0.5.3 / 53, Debug** в `~/Applications/Forelock.app`, macOS 15.7.3 / Apple Silicon. Ветка `feature/live-surface-core` создана от принятой `feature/shelf-multi-selection`, `c865d33e5b8ee158ccdb4798f62df2615086d66a`. Merge в main не выполняется. [Принятая 0.5.2](ACCEPTANCE-0.5.2.md) сохранена отдельно.

## Результат

Независимый LiveSurfaceCoordinator управляет представлением, не заменяя NotchState. Silent, Ambient, Stretch, Peek и Workspace используют существующий NSPanel, контур и SurfaceSpring. Новых окон, провайдеров, фоновой службы или сохранённой очереди нет. Подробные правила — [LIVE-SURFACE.md](../../docs/LIVE-SURFACE.md).

Реальные входы: выбранный источник MusicCoordinator и операции/ошибки ShelfModel. Playing даёт статичную ноту сбоку от камеры, paused/stopped/недостоверные данные убирают её. Изменение трека/источника обновляет то же событие без Stretch. Завершение файловой операции отмечается обработанным Workspace и не дублирует Mini Shelf; ошибка может оставить ограниченное по TTL внимание, продолжая отображаться в прежней полке.

Stretch/Peek в этой версии проверяются явно подписанными **диагностическими** событиями. Меню «Live Surface · диагностика» и соответствующие accessibility actions существуют только в Debug. В Release ни диагностических обработчиков, ни их интерфейса нет; проверено отдельной сборкой и отсутствием диагностических строк/селекторов. Устройств, Clipboard, агентов и таймеров не имитируем. Установлен Debug именно для локальной проверки механизмов до появления новых источников.

## Автоматические проверки

В настоящей WindowServer-сессии целевой запуск `LiveSurfaceTests|FileDropTests|MiniShelfTests|ShelfSelectionTests|InteractionTests|PanelIntegrationTests`: **41 тест, 0 ошибок, 0 пропусков**. После изменений Debug accessibility/новых настроек повторены **12 LiveSurfaceTests, 0 ошибок, 0 пропусков**. Проверки не заменяют сквозную ручную приёмку.

Новые тесты: P1/P2, безусловный P0, отсутствие отложенного повтора после Workspace, fullscreen off/opt-in, дедупликация без продления показа, ограниченные очередь/TTL, просроченные/некорректные события, актуальный Ambient после Stretch, Peek удержание до TTL, сброс текущего события при понижении, уникальность слотов/Nothing/недоступные данные, только свежая playing-музыка, настоящие сигналы ShelfModel с частичной ошибкой без дублирования, реальный NSPanel/верхний якорь и отсутствие новых Idle-триггеров на плечах.

Первый запуск в ограниченной shell-сессии не имел WindowServer/pasteboard: нативные тесты пропускались/падали на недоступных системных сервисах. Результат приёмки — последующий полный целевой запуск в реальной сессии, а не игнорирование этих ошибок. Новых веб-, Playwright- или мобильных тестов не запускалось.

Краткая выборка главного Debug-процесса в Ambient: около 34 MB, 2.7–3.2% CPU в двух трёхсекундных интервалах. Это короткое наблюдение всего существующего главного процесса, не отдельный замер накладных расходов Live Surface и не длительный energy benchmark. Дополнительного постоянного таймера или анимации индикатора не добавлено; публикации игнорируют неизменившийся UI payload, истечение проверяется по deadline в прежнем таймере окна.

## Сохранённая основа и ограничения

Без изменений относительно c865d33: NotchState cases/навигационная машина, NotchGeometry/SurfaceSpring, NotchPointerPolicy, FileDropLayout/FileDragProbe, DropHostingView, native file drag source/group items, ShelfModel/Repository и формат хранения, MusicCoordinator/MusicViews, ForelockMusic/MediaRemote. В контроллер добавлены только контекст приоритета, цель размера и разрешение ввода в видимый Peek; Ambient/Stretch не расширяют область кликов Idle. Невидимая область File Drop остаётся прежней временной механикой, включаемой наблюдаемым drag.

Fullscreen policy и TTL удержания Peek проверены тестами. Reduced motion использует прежнюю ветку мгновенной установки размера, без отдельной новой анимации. Физическая сессия fullscreen, системное переключение Reduce Motion и физическое удержание указателя в Peek здесь не заявлены проверенными. Внешний дисплей отдельно не проверялся. Ограничения существующих музыкальных провайдеров и глобальной команды MediaRemote сохраняются. Новых интеграций нет.
