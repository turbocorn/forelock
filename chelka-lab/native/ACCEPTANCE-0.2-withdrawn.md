## Исправление, найденное при живой приёмке

При нажатии на карточку приложение ошибочно включало магнитную область загрузки: системный drag pasteboard сохраняет URL предыдущего переноса, а проверка нажатой кнопки мыши принимала это за новое входящее перетаскивание. Карточка исчезала до начала NSDraggingSession.

Исправлено в NotchWindowController: отслеживается, началось ли нажатие внутри панели. Такие нажатия исключены из входящего drag detection, а активный исходящий NSDraggingSession блокирует магнитную реакцию. Входящий перенос из другого приложения продолжает работать. Пользователь повторно проверил обновлённую установленную сборку и подтвердил копирование в Finder.

Инструмент управления Mac вернул `AXError.notImplemented` для drag карточки, поэтому системный жест принят по реальной ручной проверке пользователя, а не по синтетическому тесту.
